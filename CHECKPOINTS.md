# Weekly Acceptance Gates

Only advance when evidence supports the work.

## Week 1 — Networking
- [ ] Calculate a /26 range correctly.
- [ ] Explain DNS → TCP/TLS → HTTP → application.
- [ ] Identify the default route on the lab machine.
- [ ] Diagnose and fix one controlled connectivity issue.
- [ ] Publish an incident report with commands, observations, root cause, fix and verification.
**Pass:** every item has evidence.

## Week 2 — Data
- [ ] Explain the event schema and constraints.
- [ ] Write SQL joins and aggregations.
- [ ] Persist event data across container recreation.
- [ ] Process at least 10,000 synthetic events.
- [ ] Restore a backup and validate integrity.
**Pass:** every item has evidence.

## Week 3 — Cloud
- [ ] Explain compute, storage, networking, IAM and monitoring.
- [ ] Draw a VPC with public/private subnets and CIDR.
- [ ] Explain routes, IGW, NAT, security groups and network ACLs.
- [ ] Explain least privilege and secret handling.
- [ ] Document costs and teardown; do not claim an unperformed deployment.
**Pass:** every item has evidence. A cost-aware design can substitute for live deployment.

## Week 4 — Operations
- [ ] Resolve three timed incidents using evidence.
- [ ] Complete at least five incident reports.
- [ ] Reproduce the setup from documentation.
- [ ] Run automated checks and capture results.
- [ ] Deliver a short demo and explain trade-offs.
**Pass:** every item has evidence.

Final status: **Ready to present** only when all gates pass and the project is reproducible.
